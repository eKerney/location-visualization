## New Astro Blog

For the #30DayMapChallenge 2025 I've decided to make the move from Jekyll to Astro for the Location Visualization blog.  I enjoyed the simplicity and markdown first content for jekyll, which worked well for a personal site/blog hosted on github pages.  Customizing some portions were becoming increasingly difficult, and I remember trying unsuccessfully for some time to change an avatar image, on top of installing ruby and gem packages when I wanted to update content and run the site locally.  Does anyone remember the jekyll build serve etc... command each time?  I certainly couldn't remember.    

Never one to pass an opportunity to incorporate something new into a workflow, I've started a new site using **ASTRO**.  The docs claim that Astro is a modern web framewrok with a mission to build fast, content-focused websites.  There are many community templates for blog and personal sites, and does give me Jekyll vibes in JS form.  I'll have more feedback as I continue to build the site, though I like the strict Typescript enforcement and markdown based content for blog posts.  Since I adopted markdown as my primary writing style I've never wanted to go back to proprietary document editors, and find it enjoyable and I don't get too distracted with formatting and moving things around with a mouse.  If anyone can get the .mdx files to work with your markdown LSP in `neovim` give me a shout please!  This site is using the [spectre]() template btw.  I've generated the glowing avatar with gemini nano-banana as well, and have had some fun using gen AI to create some images on the fly.  All the other images here are clips from maps, apps and graphs that I've created.
