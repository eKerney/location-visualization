## 30DayMapChallenge2025 Day14

Well it's not been the best Map Challenge so far.  Like many of you I've been preoccupied with many things and have not yet made any maps!  If you take a look at my [other post](), in addition to the new Astro based site, I was looking into some more exploration into the GeoRust ecosystem.  Particularlay I was hoping to explore the Rust kernel for Jupyter notebooks and creating some basic visualizations with plotlars and other rust libraries for charts and maps.  



[OSM Data made easy with Quack OSM and Kamil Raczycki](https://www.youtube.com/live/r6cWiSULgYs?si=eWEjCnh0zOERAuQV0)

For the #30DayMapChallenge 2025 I've decided to make the move from Jekyll to Astro for the Location Visualization blog.  I enjoyed the simplicity and markdown first content for jekyll, which worked well for a personal site/blog hosted on github pages.  Customizing some portions were becoming increasingly difficult, and I remember trying unsuccessfully for some time to change an avatar image, on top of installing ruby and gem packages when I wanted to update content and run the site locally.  Does anyone remember the jekyll build serve etc... command each time?  I certainly couldn't remember.
